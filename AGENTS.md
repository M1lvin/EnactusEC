# AGENTS.md

## Цель
design-variants/ заморожена, сайт редактируется только в корне

Официальный сайт студенческого клуба Enactus EC (Инженерный колледж Light Academy, Бишкек). Многостраничное приложение с навигацией через React Router. На телефоне меню прячется за кнопку.

## Язык
- Сайт на русском.
- Фраза «Бирге күчтүүбүз!» используется только как одна подпись на кыргызском. Других фраз на кыргызском не добавлять.

## Стиль
- Современный, чистый, аккуратный, как у профессиональной студии.
- Крупные заголовки, много воздуха.
- Тёмный фон с золотыми акцентами, как в логотипе Enactus.
- Анимации: плавное появление блоков при прокрутке и аккуратные эффекты при наведении. Не перегружать сайт.
- Обязательно учитывать настройку prefers-reduced-motion.

## Технологии
- React + Vite, React Router, CSS.
- Данные проектов, команды, достижений и партнёров хранятся в `src/data/*.js`, а не в компонентах.

## Жёсткие правила
1. Не придумывать факты: даты, имена, описания проектов, цифры, ссылки. Всё, чего нет в content.md, помечать как TODO и сообщать.
2. Не добавлять функции, которых нет в задании (формы, базы данных, отправку почты), без явного разрешения. Обязательные по заданию: форма вступления с проверкой полей, фильтр проектов по направлению, анимированные счётчики, useState и useEffect. Их добавлять без дополнительного разрешения.
4. Не работать с секретами. Ключи и пароли не писать в код и не запрашивать.
5. Вносить изменения маленькими шагами, по одной задаче за раз, и делать маленькие коммиты. После каждого шага кратко писать, какие файлы изменены и почему.
6. Перед изменением файлов кратко перечисли, что собираешься сделать, и жди ответа владельца в чате.
7. Шапку можно менять по указаниям владельца; классы и JS-классы мобильного меню сохранять.
8. Логотип клуба не перекрашивать без согласия клуба.
